{{ colEditor.draft.type==='formula' ? 'Formula' : 'Formula on the value typed in this column' }}
Use {This} for the value typed in this cell. {This[-1]} is this column, one row above (like Excel A1 when you are on A2). {This[-1]}+1 increments it. Ranges: SUM({Qty[-2:0]}) is Qty on this row and the two above. Dates are day/month/year: 01/01/2026+1 → 02/01/2026. The formula is the column default for every row. In Architect Mode you can also write B2 or Customers!B2, or type = on the grid and click cells. Same-row clicks insert {Qty}.
